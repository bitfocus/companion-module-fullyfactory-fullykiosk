# companion-module-fullyfactory-fullykiosk

Bitfocus Companion module for [Fully Kiosk Browser](https://www.fully-kiosk.com) (REST API).

See [HELP.md](./companion/HELP.md) and [LICENSE](./LICENSE)

## Getting started

`yarn` installs everything; `yarn build` compiles; `yarn dev` runs the compiler in watch mode; `yarn package` builds a loadable `.tgz`.
